# Сводка perf: baseline и fused

Вход: `base_photo.png`, 22 022 007 байт; 50 итераций, 5 повторов, CPU 3.
Параметры команд: min/avg/max chunk = 4096/10240/65536, batch = 8192.
Источники: `baseline_*.txt` и `fused_*.txt` в этом каталоге.

Дельта = `(fused / baseline − 1) × 100%`: минус означает уменьшение.
Для строк с долей в процентах дельта тоже относительная, не в процентных пунктах.
Счётчики — средние по запускам; `±` у них — относительный разброс из perf,
у времени — абсолютный разброс в секундах. Производные показатели рассчитаны по средним.

и весь процесс; baseline сохраняет чанки перед хэшированием, fused обрабатывает их потоком.
