# Сравнение размеров чанков

Во всех прогонах `BLAKE3_BATCH` зафиксирован на 8 KiB. Обрабатывался файл размером около 21 MiB, по 50 итераций на запуск. В таблице приведено среднее время обработки; ускорение рассчитано как `Baseline / Fused`.

| Min / Avg / Max, KiB | Fused, с | Baseline, с | Ускорение Fused |
|---|---:|---:|---:|
| 4 / 8 / 64 | 1,480 | 2,589 | 1,75× |
| 4 / 16 / 64 | 1,387 | 2,398 | 1,73× |
| 4 / 32 / 64 | 1,298 | 2,443 | 1,88× |
| 8 / 32 / 128 | 1,309 | 2,448 | 1,87× |
| 16 / 64 / 256 | 1,271 | 2,371 | 1,87× |
| 32 / 128 / 512 | 1,233 | 2,351 | 1,91× |

## Аннотация

Абсолютное время зависит от состояния системы и частоты процессора, поэтому результаты разных сессий напрямую сравнивать не следует. В предыдущей сессии для крупных чанков время было почти вдвое меньше при сопоставимом числе циклов. Для сравнения реализаций важнее относительное ускорение внутри одной серии замеров: Fused стабильно быстрее Baseline примерно в 1,7–1,9 раза.

В текущих данных увеличение целевого размера чанка в целом улучшает скорость, особенно у Fused. Вариант `32 / 128 / 512 KiB` остаётся самым быстрым;
